# 开口说 · Speak Up

分场景的英语口语**模板**站，**美式英语为主**，附易经文化行业专业单词本。

在线：https://nevergiveup0618.github.io/spoken/

## 核心：先给模板，自己填空

不是背句子，是记骨架。一个 `Could I have ___, please?` 就能换出十几句。

```
Could I have  [ 想要的东西 ]  , please?
能给我 …… 吗？
可换：some water 一杯水 · the menu 菜单 · a bag 一个袋子 · the receipt 收据 …
```

点任意一个替换词，它会填进空里并念给你听。

| 层 | 数量 | 说明 |
|---|---|---|
| **核心句型** | 20 个 / 154 个替换词 | 跨场景通用骨架，顶掉大半场合 |
| **场景模板** | 108 个 / 534 个替换词 | 每个场景 2 个专属模板 |
| **现成例句** | 54 场景 × 3 句 | 按使用频率 ★★★ → ★★ → ★ 排 |
| **专业单词本** | 8 类 / 72 词 | 易经、八字、风水、术数的行业英文 |

模板 + 替换词一共能组合出 **688 个完整句子**。

十个分组：出行、住宿、吃饭、购物、生活、社交、工作、应急、**东南亚**（砍价/嘟嘟车/寺庙/按摩/拒绝拉客）、**易经专业**（用英语介绍这一行、解释易经八字风水、咨询开场、边界免责、报价交流）。

每句例句还给：**什么时候用** / **对方会说**（对方大概率的回答）/ **换个说法**。

## 功能

- **点读**：美音朗读，可切慢速；场景页顶部可连播。发音走**预合成 mp3**（1186 条），不依赖手机语音引擎，所以**微信里打开也能出声**
- **今日五句**：每天从最高频句子里挑五句
- **五种练习，全部客观判分**
  - **模板填空** — 给模板和要表达的意思，选对的词填进空里
  - 中译英四选一
  - 连词成句（打乱的单词按语序点回去）
  - **跟读打分**（麦克风识别后逐词比对，给 0–100 分并标出漏词）
  - 专业单词中英互测
- **SRS 复习**：答对推远、答错拉近，间隔 1/2/4/8/16/30 天
- 收藏、中英文搜索（模板/例句/专业词一起搜）、PWA 可加桌离线

## 视觉

图标是**自绘的一套线性 SVG**（`index.html` 里的 sprite）：统一 24×24、统一 1.6 笔画、圆角端点、单色继承 `currentColor`。**不用 emoji** —— emoji 在不同系统渲染风格不一（立体/扁平/配色各异），拼在一起必然杂乱。测试里有一条断言禁止界面再混入 emoji。

场景列表不放图标，用序号 + 色条 + 排版层级区分，比堆图标干净。

## 结构

```
index.html   界面、样式、SVG 图标 sprite
app.js       全部逻辑，不写死任何句子
data.js      唯一内容源：GROUPS / SCENES（含 pat 模板）/ PATTERNS / TERMSETS
sw.js        离线缓存（不预缓存 mp3）
audio/       预合成发音 mp3+ manifest.js 索引
tools/gen_audio.py  用 edge-tts 生成发音（增量，只补缺的）
tests/test.js    内容自检（结构 / 频率排序 / 模板占位符 / 中英混排 / 美式口径 / 图标有效性 / 缓存版本号）
tests/smoke.js   jsdom 交互冒烟测试（走完主要路径，含模板点词填空）
```

## 改内容

只改 `data.js`，然后两个测试都要跑：

```bash
node tests/test.js && node tests/smoke.js
```

**改了英文内容后必须重跑发音生成**，否则新句子在微信里没声音：

```bash
.venv/bin/python tools/gen_audio.py          # 增量，只补缺的
.venv/bin/python tools/gen_audio.py --clean  # 顺便清掉已删内容的旧音频
```

（首次需要 `python3 -m venv .venv && .venv/bin/pip install edge-tts`）

**改完必须同时 bump 三处版本号**（否则手机上看不到新版本）：`sw.js` 的 `CACHE`、`index.html` 与 `sw.js` 里的 `?v=`。测试会校验后两处是否一致。

模板写法约束（测试会卡）：
- 英文模板句必须且只能有**一个** `{}` 占位（渲染只支持一个空）
- 中文模板也要有 `{}`
- 每个模板至少 4 个替换词，每项是 `["英文", "中文"]`
- 填进模板后不能出现双空格或 `to to` 这类重复词

## 已知边界

- 跟读打分依赖浏览器语音识别（Chrome / Safari 支持）。**微信内置浏览器不支持语音识别**，跟读会自动降级成「念顺了 / 不太顺」自评；发音不受影响（走 mp3）。
- mp3 里没有的文本（例句的「对方会说」等）退回系统 TTS，微信里这部分可能没声音。
- 「我的 → 发音自检」可以当场确认走的是哪条通道。
