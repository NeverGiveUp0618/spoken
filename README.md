# 开口说 · Speak Up

分场景的英语口语速查与练习站，**美式英语为主**，附易经文化行业专业单词本。

在线：https://nevergiveup0618.github.io/spoken/

## 内容

| 模块 | 数量 | 说明 |
|---|---|---|
| 生活场景 | 10 组 / 54 场景 / 162 句 | 每个场景 **三句**，按使用频率 ★★★ → ★★ → ★ 从高到低排 |
| 专业单词本 | 8 类 / 72 词 | 易经、八字、风水、术数的行业英文 |

十个分组：出行、住宿、吃饭、购物、生活、社交、工作、应急、**东南亚**（砍价/嘟嘟车/寺庙/按摩/拒绝拉客）、**易经专业**（用英语介绍这一行、解释易经八字风水、咨询开场、边界免责、报价交流）。

每句给四样东西：

- **英文 + 中文**
- **什么时候用** — 说的时机和注意点
- **对方会说** — 对方大概率的回答（听懂回答比会说更重要）
- **换个说法** — 同义替换

## 功能

- **点读**：点 🔊 美音朗读，🐢 慢速；场景页右上 ▶ 连播三句
- **今日五句**：每天从最高频句子里挑五句
- **四种练习，全部客观判分**
  - 中译英四选一
  - 连词成句（打乱的单词按语序点回去）
  - **跟读打分**（麦克风识别后逐词比对，给 0–100 分并标出漏词）
  - 专业单词中英互测
- **SRS 复习**：答对推远、答错拉近，间隔 1/2/4/8/16/30 天
- 收藏、中英文搜索、PWA 可加桌离线

## 结构

```
index.html   界面与样式（单文件）
app.js       全部逻辑，不写死任何句子
data.js      唯一内容源：GROUPS / SCENES / TERMSETS
sw.js        离线缓存
tests/test.js    内容源自检（结构 / 频率排序 / 中英混排 / 美式口径 / 引用完整性）
tests/smoke.js   jsdom 交互冒烟测试（走完主要路径抓运行时报错）
```

## 改内容

只改 `data.js`，然后：

```bash
node tests/test.js && node tests/smoke.js
```

**改完必须同时做两件事**（否则手机上看不到新版本）：

1. `sw.js` 里的 `CACHE` 版本号 +1
2. `index.html` 和 `sw.js` 里 `data.js?v=` / `app.js?v=` 的版本号 +1

## 已知边界

- 跟读打分依赖浏览器语音识别（Chrome / Safari 支持）。不支持的浏览器自动降级成"念顺了 / 不太顺"自评。
- 朗读用系统 TTS，优先挑 en-US 声音；不同设备音色不同。
