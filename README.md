# 开口说 · Speak Up

分场景的英语口语**模板**站，**美式英语为主**，附易经文化行业专业单词本。

在线：https://nevergiveup0618.github.io/spoken/

## 核心：先给模板，自己填空

不是背句子，是记骨架。一个 `Could I have ___, please?` 就能换出十几句。

```
Could I have  [ 想要的东西 ]  , please?
能给我 …… 吗？
可换：some water 一杯水 · the menu 菜单 · a bag 一个袋子 · the receipt 收据 …
```

点任意一个替换词，它会填进空里并念给你听。

| 层 | 数量 | 说明 |
|---|---|---|
| **核心句型** | 20 个 / 154 个替换词 | 跨场景通用骨架，顶掉大半场合 |
| **场景模板** | 92 个 / 454 个替换词 | 每个场景 2 个专属模板 |
| **现成例句** | 46 场景 × 3 句 | 按使用频率 ★★★ → ★★ → ★ 排 |
| **微对话** | 46 段 / 326 句 | 每个场景一段完整往返，可整段连播、可角色演练 |
| **专业单词本** | 8 类 / 72 词 | 易经、八字、风水、术数的行业英文 |

## 内容来源

**全部由我（Claude）撰写，没有外部语料源，无出处可溯。** 分层看可靠度：

- **句型骨架**是英语标准高频句式，语法和得体性没问题
- **易经术语英译**多数是英文圈通行译名（trigram/hexagram 出自 Wilhelm-Baynes 体系，Four Pillars of Destiny、Day Master、form school / compass school、Flying Star 是英文命理风水著作的通行说法），但**未逐条对照文献核实**；个别条目在 note 里标了不确定
- **使用频率排序（★）是主观判断，没有语料库词频支撑** —— 这是全站最软的一层

模板 + 替换词一共能组合出 **608 个完整句子**。

九个分组：出行、住宿、吃饭、购物、生活、社交、工作、应急、**易经专业**（用英语介绍这一行、解释易经八字风水、咨询开场、边界免责、报价交流）。

每句例句还给：**什么时候用** / **对方会说**（对方大概率的回答）/ **换个说法**。

## 功能

- **点读**：美音朗读，可切慢速；场景页顶部可连播。发音走**预合成 mp3**（1058 条），不依赖手机语音引擎，所以**微信里打开也能出声**
- **今日五句**：每天从最高频句子里挑五句
- **七种练习**
  - **对话演练** — 整段来回走一遍：对方的话只放声音，轮到你先看中文自己说，再翻开对答案
  - **秒答** — 看中文，自己出声说，再翻答案对一遍。一根手指走完，微信里可用，最接近实战
  - **听懂对方** — 只放声音不给字，选对方那句是什么意思（素材是 143 句对方回答）
  - **模板填空** — 给模板和要表达的意思，选对的词填进空里
  - 中译英四选一
  - 连词成句（打乱的单词按语序点回去）
  - **跟读** — 按环境自动选三档：①能语音识别就逐词比对打分 ②不能识别但能录音，就录下你的声音跟原声 A/B 对比（**微信里走这档**）③都不行则节奏跟读：原声 → 留空档给你念 → 再放一遍
  - 专业单词中英互测
- **SRS 复习**：答对推远、答错拉近，间隔 1/2/4/8/16/30 天
- 收藏、中英文搜索（模板/例句/专业词一起搜）、PWA 可加桌离线
- **内容多的模块默认折叠**：核心句型、分组模板、单词本词条都只显示一行标题（模板句 + 中文 + 「几个换法」），点开才展开用法和替换词，分节标题右侧有「全部展开 / 全部收起」。场景页只有 2 个模板，直接展开不折叠。

## 视觉

图标是**自绘的一套线性 SVG**（`index.html` 里的 sprite）：统一 24×24、统一 1.6 笔画、圆角端点、单色继承 `currentColor`。**不用 emoji** —— emoji 在不同系统渲染风格不一（立体/扁平/配色各异），拼在一起必然杂乱。测试里有一条断言禁止界面再混入 emoji。

场景列表不放图标，用序号 + 色条 + 排版层级区分，比堆图标干净。

## 结构

```
index.html   界面、样式、SVG 图标 sprite
app.js       全部逻辑，不写死任何句子
data.js      唯一内容源：GROUPS / SCENES（含 pat 模板）/ PATTERNS / TERMSETS
sw.js        离线缓存（不预缓存 mp3）
audio/       预合成发音 mp3+ manifest.js 索引
tools/gen_audio.py  用 edge-tts 生成发音（增量，只补缺的）
tests/test.js    内容自检（结构 / 频率排序 / 模板占位符 / 中英混排 / 美式口径 / 图标有效性 / 缓存版本号）
tests/smoke.js   jsdom 交互冒烟测试（走完主要路径，含模板点词填空）
```

## 改内容

只改 `data.js`，然后两个测试都要跑：

```bash
node tests/test.js && node tests/smoke.js
```

对话写法约束（测试会卡）：每段 6–10 句、你说的不少于 3 句、双方句数差不超过 2、必须交替发言、单句不超过 16 词，且**本场景最高频那句要由「你」说出来**（否则等于没练到）。英文一律用口语缩写（`I'm` 不是 `I am`）。

**改了英文内容后必须重跑发音生成**，否则新句子在微信里没声音：

```bash
.venv/bin/python tools/gen_audio.py          # 增量，只补缺的
.venv/bin/python tools/gen_audio.py --clean  # 顺便清掉已删内容的旧音频
```

（首次需要 `python3 -m venv .venv && .venv/bin/pip install edge-tts`）

**改完必须同时 bump 三处版本号**（否则手机上看不到新版本）：`sw.js` 的 `CACHE`、`index.html` 与 `sw.js` 里的 `?v=`。测试会校验后两处是否一致。

模板写法约束（测试会卡）：
- 英文模板句必须且只能有**一个** `{}` 占位（渲染只支持一个空）
- 中文模板也要有 `{}`
- 每个模板至少 4 个替换词，每项是 `["英文", "中文"]`
- 填进模板后不能出现双空格或 `to to` 这类重复词

## 已知边界

- **跟读自动分三档**，不会出现「点了没反应」：
  - 自动判分需要 `SpeechRecognition` —— 只有桌面 Chrome 和 iPhone 上的 Safari 靠谱。**微信内置浏览器没有这个 API**；国内 Android Chrome 虽然有，但识别要连 Google 服务器，也常失败（会提示「识别服务连不上」）。
  - 微信里走**录音对比**档：`getUserMedia` + `MediaRecorder`，录完自动 A/B 对照原声，靠耳朵判。拿不到麦克风权限时再退到节奏跟读。
  - 节奏跟读不需要任何权限，任何环境都能用。
  - 当前走哪档，「我的 → 发音自检」里直接写着。
- 例句的「对方会说」（137 条，含中文对照）「换个说法」（138 条）都有 mp3，微信里同样能听。带 “ / ” 的双答法会拆句分别合成。
- 「我的 → 发音自检」可以当场确认走的是哪条通道。
